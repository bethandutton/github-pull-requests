GitHub access token

Stored in this browser only. Sent to api.github.com and nowhere else.

Where to find it on GitHub:

  1. Click your profile photo, top right of github.com, then Settings.
  2. Scroll to the bottom of the left sidebar and open Developer settings.
  3. Open Personal access tokens, then Tokens (classic).
  4. Press Generate new token, then Generate new token (classic).
  5. Tick the repo checkbox, set an expiry, then Generate token.
  6. Copy it. It starts with ghp_ and GitHub shows it only once.
